Under the hood

Every page here is a static build from versioned sources: a topic is a folder of Python and JavaScript (topics/<slug>/) rendered by a shared engine — content spec → HTML with quizzes and math typesetting, numpy-computed Plotly figures, and hand-built canvas simulations. The whole pipeline, including the Claude Code skill that drives it, lives in the repository.

Quiz scores and review progress stay in your browser (localStorage) — nothing is tracked, nothing leaves your device.
